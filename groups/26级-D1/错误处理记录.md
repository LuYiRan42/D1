# 错误处理记录（四条实测 + 一条附加）

测法：在 `groups/26级-D1/` 下用 Python 3.12 直接跑 `ask.py`，把 stdout 和 stderr 分开记录；
退出码用 `$LASTEXITCODE` 取。「连不上服务器」和「返回空内容」两条用 `tools/mock_llm.py` 起本地假模型复现，
不需要真 key、不花钱，换台机器也能重跑一遍。

## 1. 不设 key

```powershell
Remove-Item Env:LLM_API_KEY
python ask.py ask "典型使用场景是什么？"
```

- 退出码：1

**stdout**

```
（空）
```

**stderr**

```
缺少 LLM_API_KEY。设置方法：
  PowerShell:  $env:LLM_API_KEY="你的key"
  CMD:         set LLM_API_KEY=你的key
  （key 不要写进代码，也不要提交进仓库）
```

## 2. 没有 index.json

```powershell
Rename-Item index.json index.json.bak
python ask.py ask "典型使用场景是什么？"
```

- 退出码：1

**stdout**

```
（空）
```

**stderr**

```
缺少 index.json，请先运行：python minisearch.py index docs/
```

## 3. 连不上服务器（断网 / BASE_URL 写错）

```powershell
$env:LLM_BASE_URL="http://127.0.0.1:8899"   # 没有服务在听
python ask.py ask "典型使用场景是什么？"
```

- 退出码：1

**stdout**

```
（空）
```

**stderr**

```
提示：没装 requests，本次用标准库 urllib；建议 pip install -r requirements.txt
重试后仍失败：连不上服务器，检查网络或 LLM_BASE_URL
```

## 4. 模型返回空内容

```powershell
python tools\mock_llm.py 8801                 # 另一个窗口
$env:LLM_API_KEY="test"
$env:LLM_BASE_URL="http://127.0.0.1:8801/empty"
python ask.py ask "典型使用场景是什么？"
```

- 退出码：1

**stdout**

```
（空）
```

**stderr**

```
提示：没装 requests，本次用标准库 urllib；建议 pip install -r requirements.txt
模型返回了空内容，请重试或换一个模型
```

## 5. 附加：key 无效（401）

```powershell
$env:LLM_BASE_URL="http://127.0.0.1:8801/auth"
python ask.py ask "典型使用场景是什么？"
```

- 退出码：1

**stdout**

```
（空）
```

**stderr**

```
提示：没装 requests，本次用标准库 urllib；建议 pip install -r requirements.txt
401：key 无效或已过期，检查 LLM_API_KEY
```

## 小结

五条都是**退出码 1、stdout 干净、stderr 一句人话、没有 traceback**。
在 `--json` 模式下也一样：错误信息走 stderr，stdout 不会出现半截 JSON，脚本解析不会崩。
